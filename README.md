# RBS Tracker

RBS Tracker is a lightweight front-end learning and robotics portal for trainers, students, and administrators.

## Features

- Separate trainer, student, and admin portal entry points
- Responsive desktop and mobile layout
- Animated robot presentation
- Demonstration sign-in form
- Static setup with no build step or external dependencies

## Run locally

Open `index.html` directly in a browser, or serve the project from the repository root:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project files

- `index.html` - page structure and portal views
- `styles.css` - layout, responsive styles, and animations
- `app.js` - portal switching and form interactions
- `*.svg` - visual assets used by the interface
